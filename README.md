# Small Business Sales Analysis
# Project Overview

This project analyses sample sales data for a small business using Google Sheets. It demonstrates basic spreadsheet skills, sales calculations, summary metrics, business insights, and data visualization.

# Project Objectives
- Calculate total sales revenue for each product.
- Calculate total sales across all products.
- Summarize the total units sold and number of products.
- Identify the highest- and lowest-revenue products.
- Visualize sales revenue using a bar chart.

# Tools Used
- Google Sheets
- Microsoft Excel (.xlsx)

# Key Results
- Total Sales Revenue: NGN 111,500
- Total Units Sold: 16
- Number of Products: 5
- Highest Revenue: Rice — NGN 50,000
- Lowest Revenue: Sugar — NGN 12,000
- Most Units Sold: Garri — 5 units

# Business Insights

Rice generated the highest revenue, while Sugar generated the lowest revenue. Garri recorded the highest quantity sold. These findings can help a small business owner review sales performance and make informed decisions.
